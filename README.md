[![Tests](https://img.shields.io/badge/pytest-12%20passed-brightgreen.svg)](tests/)

An academic-grade, reproducible speech anti-spoofing countermeasure system developed to discriminate **Bona Fide** human speech from synthetic/converted **Spoof** speech under clean conditions and severe **controlled acoustic stress conditions** (additive Gaussian noise, room reverberation, and bandwidth limitations).

---

## Overview

Voice-based biometric systems and Automatic Speaker Verification (ASV) are highly vulnerable to synthetic speech attacks generated by modern Text-to-Speech (TTS) and Voice Conversion (VC) algorithms. While deep neural countermeasures achieve low Equal Error Rates (EER) under matched laboratory acoustic conditions, their performance often degrades sharply under environmental mismatch:
- Additive Gaussian noise (low SNR)
- Room reverberation (multipath acoustic reflections)
- Bandwidth reduction / telephony filtering

This project develops a lightweight, dual-stream convolutional countermeasure utilizing **Max-Feature-Map (MFM)** activations, combining **Linear Frequency Cepstral Coefficients (LFCC)** and **Log-Mel filterbanks**, and investigates whether acoustic hardening via multicondition training improves robustness under controlled acoustic stress.

---

## Dataset

The project is built exclusively on the canonical **ASVspoof 2019 Logical Access (LA)** benchmark:

| Partition | Total Utterances | Bona Fide | Spoof | Speakers | Attack Algorithms Present |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Train** | 25,380 | 2,580 | 22,800 | 20 (disjoint) | Known: `A01`–`A06` |
| **Development (`dev`)** | 24,844 | 2,548 | 22,296 | 20 (disjoint) | Known: `A01`–`A06` |
| **Evaluation (`eval`)** | 71,237 | 7,355 | 63,882 | 67 (disjoint) | Unseen: `A07`–`A19` |
| **Total** | **121,461** | **12,483** | **108,978** | **107** | **19 Distinct Attack Systems** |

- **Audio Window Policy**: Standardized 16 kHz sampling rate, fixed **2.0-second audio input window** (32,000 samples). Longer utterances are centrally cropped; shorter utterances are symmetrically zero-padded.
- **Partition Discipline**: Zero overlap in speakers, utterances, or spoof algorithms between training (`A01`–`A06`) and evaluation (`A07`–`A19`).

## Pipeline

```text
Audio Waveform (16 kHz, 32,000 samples)
       │
       ▼
Preprocessing (Fixed 2.0s Windowing & Epsilon Peak Normalization)
       │
       ├─────────────────────────────────────────────┐
       ▼                                             ▼
LFCC Feature Extraction                       Log-Mel Feature Extraction
(60 Linear Triangular Filters, DCT-II)        (80 Mel Filterbanks, Log Energy)
       │                                             │
       ▼                                             ▼
LFCC-LCNN Branch (4-Stage MFM Conv)           Mel-LCNN Branch (4-Stage MFM Conv)
       │                                             │
       └──────────────────────┬──────────────────────┘
                              ▼
                 Feature Fusion & Concatenation
                              ▼
                     Linear Classifier Head
                              ▼
                     Bona Fide (0) / Spoof (1)
                              ▼
                     Evaluation (EER & ROC-AUC)
```

## Installation

Clone the repository and install dependencies in a Python 3.10+ virtual environment:

```bash
git clone https://github.com/Akash-bardia/Robust-Spoofed-Speech-Detection.git
cd Robust-Spoofed-Speech-Detection

# Create and activate virtual environment
python -m venv venv
# On Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# On Linux/macOS:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

## Dataset Setup

1. Download the **ASVspoof 2019 Logical Access (LA)** dataset from [Edinburgh DataShare](https://datashare.ed.ac.uk/handle/10283/3336).
2. Extract the dataset into the repository root under `LA/` (or specify the path in `WildSpoof_Project/src/config.py`):

```text
LA/
├── ASVspoof2019_LA_cm_protocols/
│   ├── ASVspoof2019.LA.cm.train.trn.txt
│   ├── ASVspoof2019.LA.cm.dev.trl.txt
│   └── ASVspoof2019.LA.cm.eval.trl.txt
├── ASVspoof2019_LA_train/flac/
├── ASVspoof2019_LA_dev/flac/
└── ASVspoof2019_LA_eval/flac/
```

3. Parse the official protocols to create the CSV manifests:

```bash
python WildSpoof_Project/scripts/prepare_la_manifests.py
```

## Training

To train the dual-stream MFM-LCNN models from scratch:

```bash
python WildSpoof_Project/scripts/train_la_system.py
```

This trains both:
1. **Clean Baseline LCNN**: Trained on uncorrupted training utterances.
2. **Augmented LCNN**: Trained with multi-condition data augmentation (additive Gaussian noise, synthetic RIR reverberation, lowpass filtering, and SpecAugment).

## Attack-wise Evaluation

To evaluate detection performance across each of the 13 individual unseen speech synthesis and voice conversion attack algorithms ($A07$–$A19$) in the ASVspoof 2019 LA evaluation set:

```bash
python WildSpoof_Project/scripts/evaluate_la_attacks.py
```

Detailed attack-by-attack results are written to `WildSpoof_Project/results/metrics/la_attack_breakdown.csv`.

Run the automated test suite covering preprocessing, feature extraction, model forward passes, augmentations, and evaluation metrics:

pytest -v tests/
